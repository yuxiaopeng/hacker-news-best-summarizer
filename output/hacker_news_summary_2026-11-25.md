## 7. 2035提前来了

**原文标题**: 2035 came early

**原文链接**: [https://fzakaria.com/2026/11/23/2035-came-early](https://fzakaria.com/2026/11/23/2035-came-early)

文章《2035提早到来》断言，Gary Bernhardt在2014年关于JavaScript到2035年将完全主导软件的预测已经提前实现，这主要归因于大型语言模型所推动的快速发展。

作者通过`trynix.dev`——一个能让超过30万个Nix包直接在网页浏览器中执行的项目——来展示这一点。最初，`trynix.dev`依赖于缓慢的QEMU模拟，限制了其实用性。然而，一个重大突破是`unkernel.dev`（于2026年11月发布）的发现，它是一个被编译成WebAssembly的Linux内核。这一创新使得内核和系统组件能以接近原生WASM的速度运行，仅需模拟用户程序。

将`unkernel`整合到`trynix.dev`中，相比QEMU-wasm，性能得到了显著提升，达到了2到32倍。这使得`trynix.dev`转变为一个强大的平台，能够直接在浏览器中提供完善的图形（通过WebGL2的Wayland/X11）、音频（ALSA）和网络体验（通过WebSockets的curl、git、pip）。

文章以一个令人印象深刻的“浏览器套娃”（browserception）演示达到高潮：Firefox在`trynix`中运行，加载`trynix.dev`，然后在其自身内部启动另一个Firefox实例。这一复杂的壮举，让人想起Bernhardt最初演讲中的一个笑话，表明普遍的浏览器内计算的预测未来确实提前数年成为现实。

## 10. Stalwart 现已成为微软 Exchange 的无缝替代品。

**原文标题**: Stalwart is now a drop-in replacement for Microsoft Exchange

**原文链接**: [https://stalw.art/blog/microsoft-exchange-replacement/](https://stalw.art/blog/microsoft-exchange-replacement/)

Stalwart 1.2.0 is now a drop-in replacement for Microsoft Exchange, enabling organizations to self-host their mail infrastructure while allowing existing clients to connect seamlessly. This release implements critical Exchange protocols: MAPI over HTTP, Exchange Web Services (EWS), Exchange ActiveSync, and Autodiscover.

This means clients like Classic Outlook for Windows, Outlook for Mac, Apple Mail/Calendar/Contacts, and Android mail apps can connect to Stalwart as they would to an Exchange server, supporting mail, calendars, contacts, tasks, and notes. This offers a vital escape route for organizations concerned about data sovereignty, as Microsoft increasingly pushes on-premises Exchange users to Exchange Online, with older versions losing support and new features becoming cloud-exclusive.

The primary benefit is enabling a server migration without user disruption. Administrators can move mailboxes and change DNS records, and users continue working with their familiar clients. Stalwart explicitly advises against using the "new Outlook" for Windows or Outlook for iOS/Android with any self-hosted server, as these clients route all data and user credentials through Microsoft’s cloud, defeating the purpose of self-hosting.

While some Exchange protocols may eventually become obsolete, Stalwart's support acts as a necessary bridge, allowing organizations to regain data control now and transition users to open-standard clients later. Exchange compatibility is a modular, disabled-by-default feature to minimize its footprint. The Vandelay tool facilitates migration from both on-premises Exchange and Microsoft 365. Other new features include server-side mail rules, read receipts, and working hours.

The campaign involved extensive internal reconnaissance, privilege escalation, lateral movement, and data exfiltration. The actor also took steps to protect their hop server by patching a Linux IPv4 vulnerability (CVE-2026-98432). Although direct observation ceased in early November, the campaign is believed to be ongoing due to the actor's persistent access. Initial access to the Check Point servers occurred before the HFS server compromise. GreyNoise is actively sharing intelligence with international partners and CERTs to notify victims.

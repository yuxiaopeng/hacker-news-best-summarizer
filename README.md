文章讨论了改进AI写作（如指令中的简化技术英语）和检测AI写作（如Pangram）的努力，以维护作者和读者之间的“社会契约”。最终，作者渴望能够传达意图、情感和解读的真实人类写作，担心过度依赖AI会导致肤浅的理解和宝贵人类洞察力的丧失。他总结道，有意识的人类写作将变得更有价值，因为他不想阅读别人（或机器）没有真正写出来的东西。

## 5. GPT-6 日月

**原文链接**: [https://openai.com/index/introducing-gpt-6-sol-and-luna/](https://openai.com/index/introducing-gpt-6-sol-and-luna/)

OpenAI 发布了 GPT-6 Sol 和 Luna，这是新的高性价比模型，旨在让前沿智能的获取途径不再局限于其旗舰模型 GPT-6 Astra。这些模型采用与 Astra 相似的训练方法，将专业工作、事实性、编码、计算机使用和对齐性方面的进步带到了更经济的层级。

一个关键特性是，与前代 GPT-5.6 相比，它们的 API 定价降低了 50%，大大降低了使用成本。例如，GPT-6 Sol 的输入价格从每百万 token 4 美元降至 2 美元，输出价格从 20 美元降至 10 美元。

在性能方面，GPT-6 Sol 和 Luna 展现出显著的提升。在 AutomationBench 和 Agents’ Last Exam 等基准测试中，GPT-6 Sol 以远低于竞争对手 Claude Opus 5 和 Fable 5.1 的成本，实现了更优异的性能。它们还提供了改进的事实性、更强的编码能力（在 FrontierCode 和 DeepSWE 上，以更低的成本达到或超越竞争对手），以及更高效的计算机使用。

新模型还采用了 GPT-6 Astra 增强的协作风格，提供更清晰、更简洁、更少专业术语的回复。

进一步的效率提升来源于 GPT-6 改进的提示缓存，它提供了更高的缓存命中率、更快的代理响应，对缓存的输入 token 提供 90% 的折扣，同时还引入了新的诊断工具。

GPT-6 Sol 和 Luna 今日起已在 ChatGPT Work 和 Codex 中向付费订阅者开放，而 GPT-6 Luna 则可在桌面应用中供免费和 Go 用户访问。它们还可通过 OpenAI API 访问，接口名称分别为 `gpt-6-sol` 和 `gpt-6-luna`。

## 7. 斯诺登档案发生了什么？

**原文标题**: What happened to the Snowden archive

**原文链接**: [https://libroot.org/posts/what-happened-to-the-snowden-archive](https://libroot.org/posts/what-happened-to-the-snowden-archive)

斯诺登档案的发布在2019年5月29日实际上已停止，随着The Intercept发布其最后一批文件并关闭其档案。其他主要媒体则更早停止发布：《卫报》在2014年2月，《明镜周刊》在2015年1月，以及《纽约时报》/ProPublica在2015年8月。从那时起，没有任何实体发布过新的文件。

《卫报》收到了大约58,000份文件，立即面临来自英国政府的压力，包括一份机密的“D通知”（D notice）以及2013年7月象征性地销毁其在伦敦的电脑（尽管副本存在于其他地方）。尽管拥有大量资料，《卫报》在九个月内仅发布了约30份文件（占0.05%），并于2014年2月停止了文件发布。其编辑艾伦·拉斯布里杰（Alan Rusbridger）援引了与当局的协商，以及遵循斯诺登将关注点放在监控/隐私而非战时情报的要求。雅各布·阿佩尔鲍姆（Jacob Appelbaum）批评《卫报》向国家妥协了编辑自主权。拉斯布里杰后来还暗示“兴趣减弱”，尽管这一说法与该报自身的增长以及其他媒体的持续成功相矛盾。

尽管《卫报》继续根据这些文件进行报道并与合作伙伴分享，但它停止了发布原始资料。格伦·格林沃尔德（Glenn Greenwald）和劳拉·波伊特拉斯（Laura Poitras）证实，他们仍然拥有“数十万份”文件的完整副本，坚称这些文件持续具有重要意义，但两人在七年内都没有发布任何新内容，也未对这种沉默做出解释。文章强调了一个显著的空白：尽管存在大量未发布的档案且公众需求得到认可，为何新文件的发布停止了。

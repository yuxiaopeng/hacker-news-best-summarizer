玛格丽特·汉密尔顿（Margaret Hamilton），这位曾领导美国国家航空航天局（NASA）阿波罗计划软件工程团队的极具影响力的计算机科学家，于9月30日去世，享年90岁。她在麻省理工学院（MIT）仪器实验室的团队开发了开创性的机载飞行软件，成功将人类送上月球。

## 5. Show HN: Bigwords.page – 将任意屏幕变成标牌。网址即应用。

**原文标题**: Show HN: Bigwords.page – Turn any screen into a sign. The URL is the app

**原文链接**: [https://bigwords.page/](https://bigwords.page/)

Bigwords.page is a web application that instantly transforms any screen into a customizable full-screen sign, timer, or message, entirely through a URL. It operates on a "no account, no app, nothing stored on a server" principle, making it private and portable, as all display information is embedded within the URL fragment and never sent to a server.

Users can create signs for diverse applications, including arrival greetings, quiz timers, Wi-Fi password displays (with QR codes), room signs, news tickers, and event countdowns. The platform offers extensive customization: text styling via Markdown, adjustable background and foreground colors, various fonts, and animations. Messages can be split into rotating slides, and dynamic countdowns can be set for specific durations or dates. It also supports embedding QR codes for links, Wi-Fi details, and even custom images.

Text automatically adjusts to fill any screen size, from mobile phones to smart TVs, and works across all browsers. To create a sign, users simply add their message after `bigwords.page/#` in the URL, and further customize it with `&key=value` parameters for settings like colors, fonts, and timers.

## 8. 在 Chrome 中推出 JPEG XL

**原文标题**: Shipping JPEG XL in Chrome

**原文链接**: [https://developer.chrome.com/blog/jpeg-xl-in-chrome](https://developer.chrome.com/blog/jpeg-xl-in-chrome)

Chrome 155 版本将于 2026 年 10 月 6 日发布，届时将支持 JPEG XL (.jxl) 图像解码。这是一种下一代格式，与 JPEG 相比可提供 30-50% 更高的压缩率。它支持无损压缩、HDR 和无损 JPEG 转码，使其成为高保真摄影和渐进式解码的理想选择。

推出 JPEG XL 的决定主要基于三个核心支柱：安全性、性能以及重要的开发者反馈。

为优先考虑安全性，Chrome 集成了 `jxl-rs`，这是一个纯 Rust 语言重新实现的 JPEG XL 解码器。这消除了 C++ 解码器中常见的内存安全漏洞（如缓冲区溢出和释放后使用漏洞），从而增强了浏览器抵御攻击的能力。

在性能方面，`jxl-rs` 通过利用 Rust 的 `target_feature_11` 和 `jxl_simd` 抽象层，借助现代 SIMD 硬件，实现了与非内存安全替代方案相媲美的速度。广泛的测试，包括模糊测试和 AI 代码审查，已证实其安全性和效率，未发现任何内存安全漏洞。

最后，开发者通过各种反馈渠道（特别是在 Interop 2026 项目中）表达的持续需求也发挥了关键作用。Chrome 正在积极参与 Interop 2026 JPEG XL 调查，以确保强大的跨浏览器互操作性。

鼓励开发者开始使用 .jxl 图像和动画，为更快、更丰富、更安全的网络做出贡献。

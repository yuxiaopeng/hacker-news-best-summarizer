## 3. Goldman Sachs is pulling Claude Code from its bankers and traders

**原文标题**: Goldman Sachs is pulling Claude Code from its bankers and traders

**原文链接**: [https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers](https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers)

Goldman Sachs has restricted most traders and bankers from using Anthropic's Claude Code and Microsoft's GitHub Copilot, limiting these AI coding tools primarily to engineers and "Strats." This decision, implemented in October, arises from concerns over productivity and risk. These include the potential for unreviewed code to be deployed, breaches of information barriers, a lack of understanding of agent-generated code leading to potential losses, and the high cost of agent usage.

Previously, Goldman's CIO Marco Argenti had encouraged "vibe coding" by non-technical staff, who used these tools to track client flows and model markets. However, the new guidance reverses this, though the bank's internal AI assistant (using various models) remains available firm-wide. Goldman had already restricted Claude for Hong Kong bankers in April due to contract terms.

Despite the restrictions, Goldman Sachs is a lead underwriter for Anthropic's upcoming IPO, and Anthropic engineers previously assisted Goldman in building Claude-based back-office agents. The article's analysis supports the restriction due to the significant risks of unreviewed code in a regulated financial environment and information barrier concerns. However, it criticizes Goldman's approach to the withdrawal, suggesting that frustrating users who found valid applications without providing alternatives was a misstep, and advises companies to establish clear ownership for agent-built code and maintain existing controls.

## 3. Ladybird 现已进入 Alpha

**原文标题**: Ladybird is now in alpha

**原文链接**: [https://ladybird.org/posts/alpha/](https://ladybird.org/posts/alpha/)

Andreas Kling于2026年11月23日宣布，他的浏览器Ladybird已正式进入alpha阶段，可在macOS和Linux上下载。Ladybird的独特之处在于其全新、从零开始构建的定制引擎，而非现有技术的派生。

作为alpha版本，用户应预料到某些网站可能无法正常运行，并且会偶尔发生崩溃。Kling鼓励用户直接从浏览器内部报告无法运行的网站，并发送崩溃报告，其中包含其隐私政策的详细信息。

他还公开邀请安全研究人员测试并“攻击”该浏览器，明确表示目前的安全不予保证，但报告漏洞将有助于增强Ladybird的安全性。一个关键特性是滚动更新通道，它将提供定期的自动更新，让用户无需从源代码构建即可体验其快速开发。

对于Web开发人员，Ladybird支持用于自动化测试的WebDriver和Firefox DevTools协议，并鼓励他们测试自己的网站并报告任何破坏性问题。Kling向赞助商、捐助者、测试人员和开发者表示感谢，尽管开发工作仍在进行中，但他对用户最终能亲自尝试Ladybird感到兴奋。

丰田、日产、本田以及马自达、斯巴鲁、三菱、铃木等日本主要汽车制造商，将从明年开始对各种汽车零部件进行标准化。日本汽车工业协会会长佐藤浩二宣布，这项举措旨在大幅降低生产成本，并将节省下来的资金投入到新创新中。此举源于日本汽车制造商为抵御来自中国竞争对手日益激烈的竞争而产生的“强烈危机感”。

目前正在与日本国内的汽车零部件供应商进行讨论，稍后将纳入国际供应商。尽管这三个领域是当前的重点，但日本汽车工业协会计划长期内将标准化范围扩大到整车的更多零部件。

## 6. GLM-5.4: 以我们的首个循环Transformer，迈向泛化编码

**原文标题**: GLM-5.4: Toward generalized coding with our first loop transformer

**原文链接**: [https://z.ai/blog/glm-5.4](https://z.ai/blog/glm-5.4)

GLM-5.4由Z.ai（Gantry.ai）开发，通过其“循环Transformer”引入了一项重要的架构进步，旨在超越传统的顺序代码生成，迈向通用编码。与以往逐个代码token预测的模型不同，GLM-5.4旨在模拟人类软件开发中迭代和多步骤的过程。

其核心创新在于能够将反馈循环和迭代式优化直接整合到其架构中。循环Transformer学习生成初始代码，然后模拟测试、识别错误、调试，并通过多个内部步骤完善其解决方案。这使得模型能够持续改进其输出，评估不同版本的代码，并维持其问题解决上下文的内部状态。

这种方法解决了编码的实际复杂性，编码往往涉及非线性思维、编辑和重构。通过从纯粹的生成任务转向更动态、自校正的系统，GLM-5.4有望提升代码质量，更好地处理复杂问题，并增强鲁棒性。循环Transformer代表着迈向更自主、更智能的编码代理的关键一步，这些代理能够应对更广泛、更模糊的编程挑战。

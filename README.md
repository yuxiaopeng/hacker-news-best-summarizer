**原文标题**: REA Reverse – Engineer Anything

**原文链接**: [https://rea.tools/](https://rea.tools/)

REA（逆向工程一切）是一款工具，它使编程智能体能够检查并理解软件的运作方式。它自动化了复杂的逆向工程过程，允许用户用简单的英语询问他们的智能体，以解释程序功能、解码指令、跟踪调用和恢复底层规则。

REA支持检查各种目标，包括原生二进制文件（可执行文件和库）、JavaScript和Electron应用程序，以及浏览器和运行时活动。设置简单，只需运行`npx rea-agents@latest setup`。该工具允许用户理解、更改或重建几乎任何软件，从克隆网站到从可执行文件中重构游戏逻辑。

## 7. Telegram 桌面版漏洞可导致任意用户文件被窃取

**原文标题**: Telegram Desktop vulnerability allowed any user's file to be stolen

**原文链接**: [https://beaksec.github.io/posts/telegram-desktop-one-click-account-takeover/](https://beaksec.github.io/posts/telegram-desktop-one-click-account-takeover/)

Telegram Desktop 7.2.8及更早版本存在一个严重漏洞 (CVE-2026-107181)，通过进程间通信 (IPC) 注入和任意本地文件窃取，可能导致一键式账户劫持。

该漏洞源于Telegram Desktop在已有实例运行时处理`tg://`链接的方式。新启动的进程通过本地套接字将点击的URL传递给现有实例。在此序列化过程中，分号 (`;`) 被用作命令分隔符。关键在于，URL本身中的分号未被转义，这使攻击者能够将额外命令注入指令流。

这些注入的命令随后可以调用一个内部的`interpret:` URI方案。该方案最初旨在用于Telegram的内部发布流程，可以在未经任何用户确认或授权检查的情况下，读取磁盘上的任何文件并将其发送到指定的聊天。

为了促成攻击，攻击者首先会将受害者添加到一个Telegram群组中。然后，他们会发布特制的文本“指令文件”（例如 `instructions1.txt`），其中包含诸如 `channel: <攻击者_聊天ID>` 和 `file: <要窃取的文件路径>`（例如 `tdata/key_datas`）等命令。由于Telegram群组文件的默认自动下载设置（最大8 MB），这些文件会自动保存到受害者机器上一个可预测的位置（例如 `Downloads\Telegram Desktop`）。相对路径，如 `interpret:../../../Downloads/Telegram%20Desktop/instructions.txt`，允许攻击者在不知道受害者用户名的情况下引用这些文件。

最后，攻击者会发送一个`https://`链接（因为Telegram聊天中的`tg://`链接会在进程内处理），该链接重定向到一个精心制作的`tg://` URL，其中包含多个注入的`OPEN:interpret:`命令。受害者点击此链接后，存在漏洞的Telegram实例将执行这些命令，将目标文件泄露到攻击者的群组。如果受害者未设置本地密码，窃取特定的`tdata`文件（`key_datas`、`D877F783D5D3EF8Cs`和`D877F783D5D3EF8C/maps`）将允许攻击者重构会话并劫持账户。

该漏洞已在Telegram Desktop 7.2.9版本中得到修复。强烈建议用户升级。启用“保存每个文件时询问位置”设置也可以通过阻止指令文件自动下载来减轻风险。

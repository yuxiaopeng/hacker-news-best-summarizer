**原文链接**: [https://github.com/ankidroid/Anki-Android/issues/21656](https://github.com/ankidroid/Anki-Android/issues/21656)

AnkiDroid，一款广受欢迎的免费抽认卡应用，因Google关于外部捐款链接的支付政策，面临自2026年9月11日起从Google Play下架的命运。该应用引导用户前往Open Collective进行捐款，其财务托管方Open Source Collective拥有美国国税局（IRS）501(c)(6)免税地位。

Google的政策允许“免税捐款”的外部链接，但最初将501(c)(3)列为经过验证的免税组织的示例。在AnkiDroid提供了其501(c)(6)地位证明后，Google却反复声明该组织“不免税”，且未解释为何501(c)(6)不符合要求，尽管这是该组织公认的免税地位（尽管对捐赠者而言，捐款不可抵税）。

AnkiDroid是一个由志愿者维护的项目，仅依靠这些捐款维持运营。为了防止应用下架，该项目已被迫在抗议下从其Play商店版本中删除了捐款链接，自2026年8月28日以来，其更新一直遭到拒绝。他们正在向Google寻求澄清，以确定501(c)(6)是否符合“免税捐款”的标准，并呼吁读者分享他们的困境，尤其是与Google员工分享，但不要直接联系Google客服。

作者详细阐述了Zitron在2024年11月的预测，即Meta、谷歌和微软等大型科技公司“正在消亡”，并且由于无法实现增长，正在“围绕AI挣扎”。文章通过展示这些公司2023-2026年的实际收入和利润增长来反驳这一观点，显示出显著增长，直接驳斥了Zitron关于“生态系统正在消亡”的说法。作者批评了Zitron的论证，指出其选择性地使用数据（例如，使用不准确的第三方MAU数据而不是公司报告来评估Meta），以及关于谷歌搜索问题的缺陷论点，未能考虑到YouTube和谷歌云等其他增长驱动因素。

作者与其他评论员，如Juho Snellman和Timothy B. Lee，广泛批评了Zitron的总体方法论。他们断言Zitron对数字的使用常常具有误导性、被歪曲或包含事实错误（例如，错误计算Anthropic的收入预测）。共识是Zitron的论点常常缺乏连贯性，依赖于数字上的“花招”和煽动愤怒来吸引关注，而非扎实的分析。

文章列出了Zitron从2024年2月到2025年2月的一些具体预测，包括生成式AI已达到上限、因数据枯竭而无法改进、以及OpenAI增长停滞或其收入预测荒谬等说法。文章始终将这些预测标记为“错误”，理由是模型持续改进、OpenAI等AI公司迅速增长、以及用户目标被超越（例如，Gemini用户达到7.5亿，而Zitron的预测是“不切实际”的5亿）。

总之，文章认为Ed Zitron对AI持怀疑态度的预测，无论从结果还是支撑它们的有缺陷的论证来看，都始终不准确。

## 6. 谷歌已将MV2扩展从Chrome网上应用店下架，其中包括UBO

**原文标题**: Google Has Removed MV2 Extensions from the Chrome Web Store, Including UBO

**原文链接**: [https://webiterate.dev/google-removed-extensions-ublock-origin-108/](https://webiterate.dev/google-removed-extensions-ublock-origin-108/)

Google已将所有Manifest V2 (MV2) 扩展程序，包括uBlock Origin等知名广告拦截器，从Chrome网上应用店中移除。此举于2024年6月实施，标志着Google向新的Manifest V3 (MV3) 扩展平台漫长过渡的终结，该过渡在最初的弃用时间表上经历了多次延迟。虽然现有MV2扩展程序的用户可能仍能使其正常运行，但已无法从商店进行新的安装或更新。

Google声称，MV3通过要求扩展程序明确声明权限并使用更受限制的API模型来增强安全性、隐私性和性能。然而，批评者，特别是广告拦截社区内部的批评者认为，MV3严重限制了内容拦截器的功能。新的`declarativeNetRequest` API取代了功能更强大的`webRequest` API，后者对于复杂的广告拦截至关重要，导致符合MV3标准的拦截器效果不佳。uBlock Origin的开发者Raymond Hill表达了强烈担忧，指出在MV3下，功能齐全的uBlock Origin无法运行，并承认其“精简版”(Lite) 是一种妥协。

这一转变促使关注广告拦截效果的用户考虑使用Firefox、Brave和Edge等替代浏览器，这些浏览器致力于维护对更强大广告拦截功能的支持，与Chrome的MV3限制背道而驰。

Gemini 3.8 Flash被誉为Google“迄今为止最佳的推理与编码模型”，相比3.7 Flash在软件工程、智能体任务和多步骤推理方面取得了显著进步，同时保持相同的低成本（每百万token输入0.75美元，输出3.75美元）。它的性能接近成本更高的前沿模型，通过额外的推理步骤和迭代工具调用，“更努力地工作”，在DeepSWE v1.1和HLE-Verified等基准测试中表现出色。开发者可通过API、企业用户以及Google AI Pro/Ultra用户使用该模型。

这两款模型均基于相同的底层智能，通过智能体循环加速，并增强了对抗提示注入的鲁棒性。它们包含防止滥用的安全措施，其中Flash Cyber具有更宽松的缓解措施，专为可信的网络安全专家量身定制。

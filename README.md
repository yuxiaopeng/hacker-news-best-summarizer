## 1. 我们对开放权重模型的立场

**原文标题**: Our position on open-weights models

**原文链接**: [https://www.anthropic.com/news/position-open-weights-models](https://www.anthropic.com/news/position-open-weights-models)

Anthropic首席执行官达里奥·阿莫迪澄清了Anthropic的立场，声明他们从未主张禁止开源权重AI模型。他认为，没有危险能力的开源权重模型是一种公共产品，能在没有显著成本的情况下提供价值。

阿莫迪概述了两大保护主义禁令无法解决的国家安全担忧：
1.  威权政府（如中国共产党）构建比美国更强大的AI，从而获得军事优势或进行深度压制。这一风险与模型是否开源权重或是否被美国企业使用无关。
2.  强大的AI模型被滥用于网络或生物攻击，并存在对齐问题。尽管开源权重模型由于难以施加防护或进行监控而可能带来更高的风险，但禁止美国企业使用它们并不能阻止恶意行为者。

相反，Anthropic支持三项关键措施：
1.  阻止向中国出售强大的芯片和芯片制造设备，并打击走私行为，以限制其训练先进模型的能力。
2.  打击工业规模的“蒸馏”操作，这使得像中国这样的国家能够更高效地开发复杂模型，部分规避了芯片禁令。
3.  在发布前，对所有足够强大的模型（无论是开源还是闭源）进行强制性安全测试。这将直接解决网络、生物和对齐风险，并且应该是一项全球性工作。

阿莫迪同意开源权重模型的一些好处，但不同意它们必然能改善防护措施或比攻击者更有助于防御者的观点，尤其是在生物威胁方面，他强调经验性测试而非假设。简而言之，Anthropic主张对芯片、“蒸馏”和安全测试采取有针对性的干预措施，而不是全面禁止开源权重模型。

## 4. 新HIV疫苗在临床前研究中取得前所未有的成功。

**原文标题**: New HIV vaccine shows unprecedented success in preclinical study

**原文链接**: [https://www.lji.org/news-events/news/post/new-hiv-vaccine-shows-unprecedented-success-in-preclinical-study/](https://www.lji.org/news-events/news/post/new-hiv-vaccine-shows-unprecedented-success-in-preclinical-study/)

来自莱霍亚免疫学研究所 (LJI)、斯克里普斯研究所和IAVI的科学家们开发出一种突破性艾滋病疫苗，在临床前研究中取得了前所未有的成功。这项疫苗研究于2026年7月6日发表，是首个在非人灵长类动物体内产生大量“广谱中和”抗体 (bnAbs) 的疫苗，为保护人类免受艾滋病病毒感染提供了巨大潜力。

该疫苗由LJI的Shane Crotty博士和斯克里普斯研究所的William Schief博士共同领导，它攻克了艾滋病病毒强大的防御机制：其糖衣、快速变异和形态转换，这些因素通常会阻止免疫系统产生有效抗体。该创新性的“种系靶向”方法旨在训练幼稚B细胞，包括一种“初免”疫苗，随后辅以模拟关键艾滋病病毒包膜蛋白抗原的“引导性”加强针。这种方案引导B细胞成熟，并产生稀有的、强效的bnAbs，这些抗体能够识别并中和多种艾滋病病毒株。

在恒河猴中，约有44%的个体产生了大量bnAbs，这与少数能自然产生此类抗体的人类情况相似。尽管尚未直接测试其预防感染的有效性，但血液中存在这些抗体对于潜在地阻断病毒至关重要。初免免疫原已进入人体试验阶段 (HVTN 144和IAVI G004)，并且科学家们正在推进计划，在未来的人体临床研究中评估完整的免疫方案，他们对其在人体中的成功充满乐观。

## 5. Substack作者，你需要一个网站

**原文标题**: Substack writers, you need a website

**原文链接**: [https://elizabethtai.com/2026/06/10/substack-writers-you-need-a-website/](https://elizabethtai.com/2026/06/10/substack-writers-you-need-a-website/)

文章强烈建议Substack的作者建立并维护自己的独立网站，认为Substack应仅被视为一个分发渠道，而非数字家园。作者批评了作家日益增长的趋势，即便是链接了自定义域名，也把Substack作为其主要的在线存在，因为与完整的内容管理系统相比，这限制了对搜索引擎优化（SEO）和自定义的控制。

核心论点是，仅仅依赖包括Substack在内的任何平台，都会使作者成为“数字佃农”或在租赁土地上的“租户”。平台不可避免地会改变规则、优先考虑利润，并可能丢失内容或改变算法偏见（通常偏向以美国为中心的叙事），从而危及作者的长期可见度和作品。平台所提供的“便利的诱惑之声”，以及对受众和变现的承诺，被认为是一个安全空间的幻觉。

相反，作者们应该采用POSSE（在自有网站发布，在其他地方分发）方法。这意味着首先在个人网站（他们拥有并控制的域名）上发布原创内容，然后利用Substack、X或Bluesky等平台来放大和分发这些内容，将读者引导回自有网站。维护独立网站长达28年的约翰·斯卡尔齐被引用为这种持久方法的典范。文章总结道，将作品固定在具有RSS等开放分发渠道的独立网站上，可以保护内容免受平台不稳定和消耗的影响，并强调平台的作用应该是寻找读者并将其“带回你的家”。

## 7. Codex Security

**原文标题**: Codex Security

**原文链接**: [https://github.com/openai/codex-security](https://github.com/openai/codex-security)

Codex Security, an offering from OpenAI, is a CLI and TypeScript SDK designed to identify, validate, and remediate security vulnerabilities in code. It enables users to scan repositories, review code changes, track security findings over time, and integrate security checks into Continuous Integration (CI) pipelines.

To use Codex Security, users need Node.js 22+, Python 3.10+, and access to the service. Installation is done via `npm install @openai/codex-security`, followed by `npx @openai/codex-security login`. Scans are initiated with `npx @openai/codex-security scan .`, with options to specify models (e.g., `--model gpt-5.6-terra`) and effort levels (e.g., `--effort high`).

For CI environments, authentication relies on the `OPENAI_API_KEY` environment variable. Interactive scans allow choosing between ChatGPT sign-in and an API key, while non-interactive scans prioritize the API key. Users can explicitly select credentials using `--auth chatgpt` or `--auth api-key`, and unset API keys to make ChatGPT the default.

Scan history is stored in a workbench state directory, which can be customized via `CODEX_SECURITY_STATE_DIR`. A TypeScript SDK is also available, allowing programmatic interaction through `import { CodexSecurity } from "@openai/codex-security";`. Comprehensive details on installation, authentication, and CI setup are available in the official documentation.

## 8. Kimi K3 架构概述和注意事项

**原文标题**: Kimi K3 Architecture Overview and Notes

**原文链接**: [https://sebastianraschka.com/blog/2026/kimi-k3-architecture-notes.html](https://sebastianraschka.com/blog/2026/kimi-k3-architecture-notes.html)

Kimi K3 架构代表了一个巨大的飞跃，作为迄今为止最大的开源权重模型，它相较于其前身 Kimi Linear，从 480 亿参数扩展到 2.8 万亿参数。

一个关键的补充是 LatentMoE，它类似于 Nemotron 3 Ultra，旨在压缩大型线性层。这反映了 Kimi K3 对推理效率的更广泛关注，其中许多组件都被诸如多头潜在注意力 (multi-head latent attention) 和 Kimi Delta 注意力 (Kimi Delta Attention) 等优化版本所取代。

除了效率之外，Kimi K3 还引入了“注意力残差”（继承自 Kimi Linear）以增强残差路径。它们使用注意力分数进行加权，从而连接跨层残差，持续提升性能，同时训练和推理成本略有增加。

值得注意的是，Kimi K3 背离了近期趋势，完全用 NoPE（无位置编码）取代了所有 RoPE 层，这对于前沿模型而言是一种独特的方法，也继承自 Kimi Linear。

最后，Kimi K3 引入了原生多模态支持。作者称赞此次发布是模型架构上一个真正巨大的进步。

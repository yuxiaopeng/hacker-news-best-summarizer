## 1. 法院赞同EFF：犹他州VPN法律要求技术上不可能

**原文标题**: Court agrees with EFF: Utah's VPN law demands a technical impossibility

**原文链接**: [https://www.eff.org/deeplinks/2026/10/court-agrees-eff-utahs-vpn-law-demands-technical-impossibility](https://www.eff.org/deeplinks/2026/10/court-agrees-eff-utahs-vpn-law-demands-technical-impossibility)

一名联邦法官发布初步禁令，有效阻止了犹他州旨在禁止使用虚拟私人网络（VPN）访问成人网站的SB 73法案。电子前沿基金会（EFF）对这一裁决表示欢迎，坚称该法律要求实现技术上不可能的事情，并违宪地加重了犹他州以外互联网用户和企业的负担。

今年早些时候签署生效的SB 73法案，要求成人网站要么阻止VPN用户，要么精确识别其物理位置，甚至禁止提供如何使用VPN的指导。这使得犹他州成为第一个针对使用VPN绕过年龄验证的州。法院裁定，该法律可能违反了美国宪法，因为它强迫网站对全球所有用户进行年龄验证，仅仅是为了防范他们可能身处犹他州，或者实现完美地理定位，这在技术上是不可行的。

该诉讼由Pornhub的母公司Aylo提起。EFF向犹他州商务部提交了意见，解释称VPN通过中介服务器路由流量，使得目标网站无法进行精确地理定位。这使得平台面临一个不可能的选择：阻止所有VPN流量，或完全退出犹他州。法官表示同意，指出该法律要求在“没有完美地理定位工具的情况下实现完美”。

EFF强调，SB 73法案的拟议行政规定还要求建立“商业上合理的地理位置混淆检测系统”，这将导致侵入性数据收集、不可靠的检测、普遍的错误分类以及不必要的访问阻止，严重影响全球用户隐私。

法院的初步禁令树立了一个重要的先例，确认州立法者不能将年龄验证武器化，以强制进行撒网式追踪或破坏VPN等基本安全工具。EFF将继续倡导反对这种技术上不可能且反隐私的强制规定。

**原文标题**: Apple Pass Designer

**原文链接**: [https://developer.apple.com/pass-designer/](https://developer.apple.com/pass-designer/)

Apple Wallet 卡包设计器是一款新工具，它简化了适用于 Apple Wallet 的数字卡包的创建和预览，旨在满足从本地商家到全球品牌等各种规模企业的需求。

该设计器允许用户从 Apple 提供的模板或他们自己的模板开始，并从他们偏好的设计工具中整合自定义图像，如标志和背景。其核心功能是实时预览，可精确显示卡包在 iPhone 和 Apple Watch 上的显示效果，完全还原了 iOS 和 watchOS 的渲染效果。

卡包设计器的测试版需要 macOS 27 或更高版本，并可供已使用 Apple ID 登录且完成免费开发者注册的用户下载。

关键特性包括在上下文不足时能够拒绝回答（“我不知道”），以及通过21.3%的德语预训练tokens和最少的翻译实现的原生双语设计。Kolibri通过自动化“模型工厂”流水线开发，其架构优先考虑效率，采用384个小型专家和混合注意力机制，从而实现高效的本地部署。该模型在近24万亿个tokens上进行训练，仅用三个月就从其前身迅速发展而来。

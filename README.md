## 4. 德国私营火箭创造历史，从欧洲本土成功入轨。

**原文标题**: Private German rocket makes history, reaches orbit from European soil

**原文链接**: [https://www.space.com/space-exploration/launches-spacecraft/isar-aerospace-second-launch-norway-andoya-spaceport-spectrum-rocket](https://www.space.com/space-exploration/launches-spacecraft/isar-aerospace-second-launch-norway-andoya-spaceport-spectrum-rocket)

2026年9月5日，Isar Aerospace公司的Spectrum火箭创造了历史，成为首枚从西欧大陆发射并成功进入轨道的火箭。这家德国公司高95英尺（约29米）、名为“Onward and Upward”的火箭，从挪威北部的安岛航天中心发射升空，在美国东部时间下午4点12分点火后仅七分多钟，便成功进入椭圆轨道。

这一成就并非一帆风顺。Spectrum火箭的首次飞行（代号“Going Full Spectrum”）发生在2025年3月，由于意外的排气阀打开和姿态失控，火箭在发射后不到一分钟便宣告失败。Isar Aerospace对此次异常进行了严密调查，并为第二次尝试实施了修复措施，然而，第二次尝试却因技术问题、恶劣天气及其他障碍，从2026年1月推迟至6月，多次遭遇延误。

在这次成功的飞行中，Spectrum火箭搭载了五颗立方星和一项科学实验。在进入初始椭圆轨道后，它进行了近圆化变轨，并成功部署了所有有效载荷，标志着任务圆满成功。Isar Aerospace计划让Spectrum火箭（其运载能力为2,200磅（约1,000公斤）至近地轨道）成为中小型卫星的主力运载工具，每年可生产超过30枚火箭。尽管俄罗斯几十年来一直从其欧洲领土发射火箭，但此次事件对西欧而言，具有开创性的重要意义。

**原文标题**: Cloud in a Bottle: making self-hosting accessible to everyone

**原文链接**: [https://cloudinabottle.org/blog/launch-post](https://cloudinabottle.org/blog/launch-post)

“瓶中云”旨在解决人们对现代云软件普遍存在的不满，列举了诸如激励机制错位、跟踪、广告以及“平台劣质化”等问题。作者认为，尽管云软件提供了便利，但其中心化特性却使开源创作者付出高昂代价，并使控制权从用户手中转移；而现有的自托管解决方案则存在难以使用、不安全或缺乏关键功能的问题。

“瓶中云”是一个开源的个人云平台，旨在让自托管变得易于访问且用户友好。它在Ubuntu机器上运行容器化应用程序，并通过网络服务器路由请求。这些应用程序在安全、无根、强化的容器中运行，使得现有软件只需极少改动即可运行。

除了基本的托管功能，该平台还提供可选功能，旨在打造“云智能手机”体验。这包括统一认证，允许用户一次登录其实例，即可自动访问所有应用程序。它还提供了一个API，用于应用程序之间的数据和能力共享，这类似于移动操作系统API如何实现集成体验。

该项目是开源的、可自托管的，并致力于零遥测和简洁性。Imbue公司提供了一个托管版本，以确保可访问性和项目可持续性，尽管自托管路径仍然是首选。随着其精选应用程序目录的增长和平台的成熟，“瓶中云”力求促进更多高质量开源Web软件的创建，并期望在技术爱好者之外，变得越来越易于广大受众使用。

盖洛普最新民调显示，2026年有高达89%的美国成年人认为政府腐败普遍存在，创历史新高，比去年上升了10个百分点，也是20年来的最高水平。这一激增主要由民主党人推动，他们认为腐败普遍存在的比例从2024年（拜登任期最后一年）的57%急剧上升到2026年（特朗普第二任期）的91%，与独立人士的90%持平。共和党人的观点则保持相对稳定，约为83%，这表明他们对此的深层担忧较少受执政党的影响。
